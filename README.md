# Buisphere website

A self-contained static website for Buisphere. The page is plain HTML, CSS, and JavaScript, and its images are embedded in `index.html`, so no build step or dependencies are required.

## Preview locally

Open `index.html` in a browser. The enquiry form opens a prefilled email draft in the visitor’s email app; the site does not store or send form submissions.

## Add to GitHub

1. Create a new repository on GitHub.
2. Upload `index.html`, `README.md`, and `.gitignore` to the repository root, or clone the repository and copy these files in.
3. To publish it with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. GitHub Pages will serve `index.html` as the site homepage.

All existing contact and social link destinations have been preserved. The email contact is now an icon alongside the social icons.
